# BDS — Bril Development Suite


[![Hippocratic License HL3-FULL](https://img.shields.io/static/v1?label=Hippocratic%20License&message=HL3-FULL&labelColor=5e2751&color=bc8c3d)](https://firstdonoharm.dev/version/3/0/full.html)

The **Bril Development Suite (BDS)** is a collection of tools for optimizing and analyzing Bril programs. For usage information, see the [documentation](docs/README.md).

## Development

**BDS** is being developed by Helen Ge and Pedro Pontes García for the Cornell graduate compilers course, CS 6120.
